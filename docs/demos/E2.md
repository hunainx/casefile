# Epic 2 (E2) — Investigation Core Demo Script

This script walks through the end-to-end capabilities built and verified in Epic 2 (E2):
Investigation Object Lifecycle, Objective & Scope Definition, Hierarchy of Questions (The Spine), Legitimacy Declarations, Team Roles, Templates, Health Indicators, Notes, and Tasks.

---

## Prerequisites
Ensure Postgres is running with the migrations applied:
```bash
pnpm db:migrate
```
Start the API service:
```bash
pnpm --filter @casefile/api dev
```
Default base URL: `http://localhost:3000`

---

## 1. Fast Investigation Creation (<30 seconds, INV-01)
Creates a new investigation in `draft` stage and automatically assigns the creator as `lead_investigator`.

```bash
TOKEN="<LEAD_INVESTIGATOR_JWT>"
WORKSPACE_ID="<WORKSPACE_UUID>"

INV_RESP=$(curl -s -X POST http://localhost:3000/v1/investigations \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "workspace_id": "'"$WORKSPACE_ID"'",
    "name": "Project Meridian Trade Compliance",
    "objective": "Investigate undisclosed related-party transactions and trade route violations",
    "sensitivity": "restricted"
  }')
echo $INV_RESP | jq .
INV_ID=$(echo $INV_RESP | jq -r .id)
```
**Expected Output:** `201 Created` with `id`, `stage: "draft"`, and initial scope.

## 2. Investigation Templates (INV-02, PRD §8.7)
Creates and instantiates an investigation from a reusable institutional template.

```bash
# Create Corporate Fraud Template
TPL_RESP=$(curl -s -X POST http://localhost:3000/v1/investigation-templates \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Corporate Fraud Inquiry",
    "description": "Standard checklist and question tree for fraud and asset tracing",
    "questions": [
      { "text": "Were undisclosed payments made to shell entities?", "materiality": "critical" },
      { "text": "Who approved the disbursements?", "materiality": "important" }
    ],
    "scope_defaults": {
      "inclusions": ["Bank Statements", "General Ledger", "Wire Transfer Records"],
      "jurisdictions": ["US-DE", "GB", "CH"]
    }
  }')
echo $TPL_RESP | jq .
TPL_ID=$(echo $TPL_RESP | jq -r .id)

# Create investigation using the template
curl -s -X POST http://localhost:3000/v1/investigations \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "workspace_id": "'"$WORKSPACE_ID"'",
    "name": "Vantor Holdings Financial Audit",
    "template_id": "'"$TPL_ID"'"
  }' | jq .
```

## 3. Investigation Questions — The Spine (INV-04, INV-05, INV-06, PRD §8.2)
Adds root questions with materiality (`critical`, `important`, `supporting`) and sub-questions for decomposition.

```bash
# Add a Critical Question
Q_RESP=$(curl -s -X POST http://localhost:3000/v1/investigations/$INV_ID/questions \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Did Vantor Holdings control Meridian Trading between 2019 and 2022?",
    "materiality": "critical"
  }')
echo $Q_RESP | jq .
PARENT_Q_ID=$(echo $Q_RESP | jq -r .id)

# Decompose with a Sub-Question (INV-05)
curl -s -X POST http://localhost:3000/v1/investigations/$INV_ID/questions \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "text": "What percentage of voting shares did Vantor executives hold in Meridian?",
    "parent_question_id": "'"$PARENT_Q_ID"'",
    "materiality": "important"
  }' | jq .

# List Question Tree
curl -s -X GET http://localhost:3000/v1/investigations/$INV_ID/questions \
  -H "Authorization: Bearer $TOKEN" | jq .
```

## 4. Scope, Subjects & Legitimacy Basis (INV-07, INV-08, INV-09, AC-DEF-02)
Declares topic inclusions, exclusions, and subjects. For any `private_individual`, a `legitimacy_basis` is mandatory.

```bash
curl -s -X PATCH http://localhost:3000/v1/investigations/$INV_ID \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "scope": {
      "inclusions": ["Financial ledgers", "Shipping manifests", "Board minutes"],
      "exclusions": ["Employee personal medical records"],
      "jurisdictions": ["US", "GB", "CH"],
      "subjects": [
        {
          "descriptor": "Meridian Trading LLC",
          "subject_type": "organization",
          "role": "primary_subject"
        },
        {
          "descriptor": "Marcus Vance (Managing Director)",
          "subject_type": "private_individual",
          "role": "related_party",
          "legitimacy_basis": "DOJ Subpoena 2026-CR-0012 authorization"
        }
      ]
    }
  }' | jq .
```

## 5. Definition Gate & Lifecycle Stage Progression (INV-11, AC-DEF-01)
Transitions investigation from `defining` to `collecting`. The gate verifies objective, >=1 question, and >=1 subject.

```bash
# Transition to COLLECTING (Gate 1 validation succeeds)
curl -s -X POST http://localhost:3000/v1/investigations/$INV_ID/stage \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "stage": "collecting" }' | jq .
```

## 8. Team Members, Notes & Tasks (INV-17, PRD §8.5, §8.6)
Manages investigation roles, attaches notes to targets, and assigns tasks.

```bash
# Add Member with role
curl -s -X POST http://localhost:3000/v1/investigations/$INV_ID/members \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "user_id": "<TEAM_USER_ID>", "role": "investigator" }' | jq .

# Attach Note
curl -s -X POST http://localhost:3000/v1/investigations/$INV_ID/notes \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "target_type": "investigation",
    "target_id": "'"$INV_ID"'",
    "content": "Reviewed initial trade manifests. Need cross-check with Q3 customs entries. #customs @lead"
  }' | jq .

# Create Task
curl -s -X POST http://localhost:3000/v1/investigations/$INV_ID/tasks \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Subpoena Q3 customs documentation",
    "priority": "high",
    "target_type": "investigation",
    "target_id": "'"$INV_ID"'"
  }' | jq .
```
