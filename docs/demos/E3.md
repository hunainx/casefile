# Epic 3 (E3) — Ingestion & Sources Demo Script

This script walks through the end-to-end capabilities built and verified in Epic 3 (E3):
Multi-Source Ingestion, Acquisition Records, 3-Level Deduplication, Structure-Aware Normalization, Low-Confidence OCR Flagging, Sandbox Quarantine, Near-Duplicate Diffing, Metadata Extraction, and Source Withdrawal.

---

## Prerequisites
Ensure Postgres is running with the migrations applied:
```bash
pnpm db:migrate
```
Start the API service:
```bash
pnpm --filter @casefile/api dev
```
Default base URL: `http://localhost:3000`

---

## 1. Upload Source with Acquisition Record (ING-01, ING-03, AC-ING-01)
Uploads a document with its provenance metadata.

```bash
TOKEN="<INVESTIGATOR_JWT>"
INV_ID="<INVESTIGATION_UUID>"

RESP=$(curl -s -X POST http://localhost:3000/v1/investigations/$INV_ID/sources \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "filename": "Financial_Audit_Report_2025.pdf",
    "mime_type": "application/pdf",
    "raw_text": "Executive Summary: Complete financial audit of offshore disbursements.",
    "acquisition_record": {
      "origin": "Corporate Audit Department Export",
      "custodian": "Audit Committee Chair",
      "acquisition_method": "upload",
      "authorization_basis": "Board Committee Resolution #88"
    }
  }')
echo $RESP | jq .
SOURCE_ID=$(echo $RESP | jq -r .id)
```
**Expected Output:** `201 Created` with `status: "indexed"`, `acquisition_record` populated, and chunk generated.

## 4. Near-Duplicate Document Diff (ING-08, AC-ING-07)
Detects versions of the same agreement and generates clause diffs.

```bash
# Upload Agreement v1
V1=$(curl -s -X POST http://localhost:3000/v1/investigations/$INV_ID/sources \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "filename": "Vendor_Agreement_v1.docx",
    "mime_type": "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
    "raw_text": "Clause 9.3: Standard Net 30 payment terms.",
    "acquisition_record": { "origin": "Vendor Share", "custodian": "Account Rep" }
  }' | jq -r .id)

# Upload Agreement v2
V2=$(curl -s -X POST http://localhost:3000/v1/investigations/$INV_ID/sources \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "filename": "Vendor_Agreement_v2.docx",
    "mime_type": "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
    "raw_text": "Clause 9.3: Payment terms amended from Net 30 to Immediate Wire Transfer.",
    "acquisition_record": { "origin": "Vendor Share", "custodian": "Account Rep" }
  }' | jq -r .id)

# Inspect Diff
curl -s -X GET http://localhost:3000/v1/investigations/$INV_ID/sources/$V1/diff/$V2 \
  -H "Authorization: Bearer $TOKEN" | jq .
```

## 5. OCR Confidence Flagging & Manual Correction (ING-09, ING-10, ING-11, AC-ING-05)
Ingests a degraded scan, flags low confidence, and applies investigator text correction.

```bash
# Upload degraded scan
SCAN_RESP=$(curl -s -X POST http://localhost:3000/v1/investigations/$INV_ID/sources \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "filename": "scanned_receipt_degraded.pdf",
    "mime_type": "application/pdf",
    "raw_text": "Totl Amnt: $450.0O",
    "ocr_confidence_override": 0.42,
    "acquisition_record": { "origin": "Physical Archive Box", "custodian": "Clerk" }
  }')
SCAN_ID=$(echo $SCAN_RESP | jq -r .id)

# View content block with confidence flag
DETAILS=$(curl -s -X GET http://localhost:3000/v1/investigations/$INV_ID/sources/$SCAN_ID \
  -H "Authorization: Bearer $TOKEN")
BLOCK_ID=$(echo $DETAILS | jq -r '.blocks[0].id')

# Apply manual correction (ING-11)
curl -s -X POST http://localhost:3000/v1/investigations/$INV_ID/sources/$SCAN_ID/ocr/correct \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "block_id": "'"$BLOCK_ID"'",
    "corrected_text": "Total Amount: $450.00"
  }' | jq .
```

## 6. Password-Protected File Decryption (ING-14)
Ingests encrypted file and unlocks it with investigator-supplied password.

```bash
# Upload encrypted source
ENC_RESP=$(curl -s -X POST http://localhost:3000/v1/investigations/$INV_ID/sources \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "filename": "Executive_Salaries_Protected.pdf",
    "mime_type": "application/pdf",
    "raw_text": "ENCRYPTED BINARY",
    "is_encrypted": true,
    "acquisition_record": { "origin": "HR Export", "custodian": "VP HR" }
  }')
ENC_ID=$(echo $ENC_RESP | jq -r .id)

# Supply password
curl -s -X POST http://localhost:3000/v1/investigations/$INV_ID/sources/$ENC_ID/decrypt \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "password": "HRMasterKey2026!" }' | jq .
```

## 7. Source Withdrawal with Cascading Flag (ING-17, PRD §11.1)
Withdraws an improperly obtained or privileged source.

```bash
curl -s -X PATCH http://localhost:3000/v1/investigations/$INV_ID/sources/$SOURCE_ID/withdraw \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "reason": "Outside counsel identified document as subject to attorney-client privilege."
  }' | jq .
```
