# Epic 1 (E1) — Foundation & Security Infrastructure Demo Script

This script walks through the end-to-end capabilities built and verified in Epic 1 (E1): Identity, Tenancy, RBAC, Policy, Cryptographic Audit Ledger, Object Storage, and the Fastify API Tier.

---

## Prerequisites
Ensure Postgres is running with the migrations applied:
```bash
pnpm db:migrate
```
Start the API service:
```bash
pnpm --filter @casefile/api dev
```
Default base URL: `http://localhost:3000`

---

## 1. Tenant Root Onboarding & Registration (AUTH-01)
Registers the root organization and initial tenant administrator.

```bash
curl -s -X POST http://localhost:3000/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "admin@acmecorp.example",
    "password": "CorrectHorseBatteryStaple999!",
    "name": "Alice Admin",
    "orgName": "Acme Corporation"
  }' | jq .
```
**Expected Output:** `201 Created` with `accessToken`, `refreshToken`, and user metadata containing `tenantId`.

## 2. TOTP MFA Setup & Verification (AUTH-02)
TOTP is enrolled only through an administrator's one-time link (D71): `pnpm admin:reset-link --email <email>`
prints `<server>/account/setup#token=…`, where the user sets a password and adds an authenticator app, confirmed
with a code. (`POST /v1/auth/mfa/setup` now returns `410 Gone`: a password alone must never add an authenticator.)
After enrolment, sign in with `POST /v1/auth/token` (it answers `mfaRequired`) and complete the challenge:

```bash
# Verify with current 6-digit TOTP code (e.g. from authenticator app)
CODE="<6_DIGIT_TOTP>"
curl -s -X POST http://localhost:3000/v1/auth/mfa/verify \
  -H "Content-Type: application/json" \
  -d '{
    "userId": "<USER_ID>",
    "tenantId": "<TENANT_ID>",
    "totpCode": "'"$CODE"'"
  }' | jq .
```

## 3. Credential Token Exchange & Step-Up Authentication (§45.2, D51)
Exchanges user credentials for session tokens at `POST /v1/auth/token`.

```bash
# Exchange credentials for token
curl -s -X POST http://localhost:3000/v1/auth/token \
  -H "Content-Type: application/json" \
  -d '{
    "email": "admin@acmecorp.example",
    "password": "CorrectHorseBatteryStaple999!"
  }' | jq .

# Step-Up MFA Challenge for high-risk operations (valid 5 minutes)
curl -s -X POST http://localhost:3000/v1/auth/step-up \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "totpCode": "'"$CODE"'" }' | jq .
```

## 5. Refresh Token Rotation & Family Reuse Detection (PRD §40.1)
Rotates refresh tokens and automatically revokes session family if a replayed token is detected.

```bash
REFRESH_TOKEN="<REFRESH_TOKEN>"

# 1. Normal rotation (succeeds)
curl -s -X POST http://localhost:3000/v1/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{ "refreshToken": "'"$REFRESH_TOKEN"'" }' | jq .

# 2. Replay attempt with old token (triggers reuse detection, revokes session family, returns 401 Problem Details)
curl -s -X POST http://localhost:3000/v1/auth/refresh \
  -H "Content-Type: application/json" \
  -d '{ "refreshToken": "'"$REFRESH_TOKEN"'" }' | jq .
```

## 7. Sign-in History & Device Session Management (AUTH-05, AUTH-06, AUTH-10)

## 8. Workspace Policy, Retention & Separation of Duties (WS-04, WS-05, WS-06, AUTH-09)
Configure workspace governance, confidence weights, retention floor, and separation of duties.

```bash
# Create Workspace
WS_RESP=$(curl -s -X POST http://localhost:3000/v1/workspaces \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "name": "Project Apollo Investigation" }')
WS_ID=$(echo $WS_RESP | jq -r .id)

# Fetch Policy
curl -s -X GET http://localhost:3000/v1/workspaces/$WS_ID/policy \
  -H "Authorization: Bearer $TOKEN" | jq .

# Update Governance Policy
curl -s -X PATCH http://localhost:3000/v1/workspaces/$WS_ID/policy \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "separation_of_duties": true,
    "mfa_required": true,
    "retention_policy": { "floor_days": 90, "delete_after_days": 730 },
    "confidence_weights": { "corroboration": 0.5, "source_credibility": 0.5 }
  }' | jq .
```

## 9. Immediate Membership Revocation & Ethical Walls (WS-03, WS-07)
Adds and revokes members, and configures ethical walls for matter isolation.

```bash
# Add Member
MEMBER=$(curl -s -X POST http://localhost:3000/v1/workspaces/$WS_ID/members \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{ "user_id": "<USER_ID>", "role": "reviewer" }')
MEMBER_ID=$(echo $MEMBER | jq -r .id)

# Immediately Revoke Member Across All Investigations (WS-03)
curl -s -X DELETE http://localhost:3000/v1/workspaces/$WS_ID/members/$MEMBER_ID \
  -H "Authorization: Bearer $TOKEN" | jq .

# Create Ethical Wall (WS-07)
curl -s -X POST http://localhost:3000/v1/workspaces/$WS_ID/ethical-walls \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "subject_type": "user",
    "subject_id": "<USER_ID>",
    "reason": "Prior conflict with Acme supplier"
  }' | jq .
```
