# Epic E7 Demo Walkthrough — Evidence, Citation Resolution & Provenance

This document provides a human-executable PowerShell walkthrough for **Epic E7 (Evidence, Citation Resolution & Grounding)**, verifying:
- **AC-PRV-01 & Invariant I9**: Locator verification on extraction (unverified spans discarded).
- **AC-PRV-02 & PRD §33**: Citation Resolution to exact span with bounding box, display toggle, and ±500 characters context in under 2 seconds.
- **AC-PRV-03 & Invariant I4**: Span Drift detection job and broken citation surfacing.
- **AC-PRV-04**: Full 8-link derivation chain from physical source document to admitting investigator without gaps.
- **Invariant I1**: Grounding enforcement rejecting ungrounded machine assertions at write time.
- **Evidence Review & Withdrawal**: Marking evidence `reviewed` / `disputed` and withdrawing with audited exclusion reasons.

## 2. Step-by-Step Walkthrough

### Step 1: Register Investigator Account & Setup Investigation

```powershell
# 1. Register investigator account
$reg = Invoke-RestMethod -Method Post -Uri "$API_URL/v1/auth/register" -ContentType "application/json" -Body (@{
    email = "lead-counsel@casefile-legal.example"
    password = "MasterPassword123!"
    name = "Alexandra Vance"
    orgName = "Vance Global Forensics"
} | ConvertTo-Json)

$TOKEN = $reg.accessToken
$HEADERS = @{ Authorization = "Bearer $TOKEN" }

# 2. Create Workspace
$ws = Invoke-RestMethod -Method Post -Uri "$API_URL/v1/workspaces" -Headers $HEADERS -ContentType "application/json" -Body (@{
    name = "Panama Sovereign Matter"
} | ConvertTo-Json)
$WORKSPACE_ID = $ws.id

# 3. Create Investigation
$inv = Invoke-RestMethod -Method Post -Uri "$API_URL/v1/investigations" -Headers $HEADERS -ContentType "application/json" -Body (@{
    workspace_id = $WORKSPACE_ID
    name = "Operation Kestrel Beneficial Ownership"
    objective = "Establish definitive chain of ownership and provenance for Meridian Trading Ltd"
} | ConvertTo-Json)
$INV_ID = $inv.id

Write-Host "Investigation Initialized: $INV_ID"
```

---

### Step 2: Ingest Primary Record Document with Acquisition Custody

```powershell
# Ingest Share Purchase Agreement PDF
$docText = "Pursuant to clause 14.2 of the Share Purchase Agreement, Meridian Trading Ltd transferred 100 percent beneficial ownership of Kestrel Nominees on 2019-08-12."

$src = Invoke-RestMethod -Method Post -Uri "$API_URL/v1/investigations/$INV_ID/sources" -Headers $HEADERS -ContentType "application/json" -Body (@{
    filename = "Share_Purchase_Agreement_2019.pdf"
    mime_type = "application/pdf"
    source_class = "primary_record"
    raw_text = $docText
    acquisition_record = @{
        origin = "Client Production"
        custodian = "J. Okonkwo (Head of Legal)"
        acquisition_method = "upload"
    }
} | ConvertTo-Json -Depth 5)

$SOURCE_ID = $src.id
Write-Host "Source Ingested: $SOURCE_ID ($($src.filename))"
```

### Step 3: Invariant I9 Discard Demonstration (AC-PRV-01)

Attempt to admit an extraction claiming a span whose text does NOT verify against the content block:

```powershell
try {
    Invoke-RestMethod -Method Post -Uri "$API_URL/v1/investigations/$INV_ID/evidence" -Headers $HEADERS -ContentType "application/json" -Body (@{
        source_id = $SOURCE_ID
        char_start = 57
        char_end = 77
        quoted_text = "Fabricated Offshore Entity Corp" # Mismatched text!
        evidence_type = "documentary"
    } | ConvertTo-Json)
} catch {
    $err = $_.ErrorDetails.Message | ConvertFrom-Json
    Write-Host "Invariant I9 Verification Succeeded (Rejected Fake Span):"
    Write-Host "  HTTP Status: $($_.Exception.Response.StatusCode.value__)"
    Write-Host "  Error Type: $($err.type)"
    Write-Host "  Detail: $($err.detail)"
}
```

---

### Step 4: Cite-From-Selection & Multi-Target Linking (EVID-001..003)

Admit valid evidence with bounding box and weight rationale:

```powershell
$startIdx = $docText.IndexOf("Meridian Trading Ltd")
$endIdx = $startIdx + "Meridian Trading Ltd".Length

$ev = Invoke-RestMethod -Method Post -Uri "$API_URL/v1/investigations/$INV_ID/evidence" -Headers $HEADERS -ContentType "application/json" -Body (@{
    source_id = $SOURCE_ID
    char_start = $startIdx
    char_end = $endIdx
    quoted_text = "Meridian Trading Ltd"
    page = 14
    bbox = @{ x1 = 120.0; y1 = 450.0; x2 = 380.0; y2 = 465.0 }
    evidence_type = "direct"
    weight = "strong"
    weight_rationale = "Direct corporate warranty signed by authorized directors"
} | ConvertTo-Json -Depth 5)

$EVIDENCE_ID = $ev.id
Write-Host "Evidence Admitted: $EVIDENCE_ID"
Write-Host "  Span Hash: $($ev.span_hash)"
Write-Host "  Integrity Status: $($ev.integrity_status)"
```

---

### Step 5: Citation Resolution in Evidence Viewer (AC-PRV-02 / PRD §33)

Resolve citation to open the Evidence Viewer layout:

```powershell
$start = Get-Date
$citation = Invoke-RestMethod -Method Get -Uri "$API_URL/v1/investigations/$INV_ID/evidence/$EVIDENCE_ID/citation" -Headers $HEADERS
$elapsedMs = ((Get-Date) - $start).TotalMilliseconds

Write-Host "Citation Resolution Completed in: ${elapsedMs}ms (< 2000ms target)"
Write-Host "Evidence Viewer State:"
Write-Host "  Display Mode: $($citation.rendered_view.display_mode)"
Write-Host "  Source Filename: $($citation.source.filename)"
Write-Host "  Custodian: $($citation.source.custodian)"
Write-Host "  Cited Text: $($citation.cited_text)"
Write-Host "  Highlighted Full Snippet: $($citation.rendered_view.full_text_snippet)"
Write-Host "  Is Broken: $($citation.is_broken)"
```

### Step 6: Full 8-Stage Provenance Derivation Chain (AC-PRV-04)

Inspect the complete unbroken derivation chain from physical source to investigator:

```powershell
$provenance = Invoke-RestMethod -Method Get -Uri "$API_URL/v1/investigations/$INV_ID/evidence/$EVIDENCE_ID/provenance" -Headers $HEADERS

Write-Host "Provenance Derivation Chain (Complete: $($provenance.is_complete)):"
$provenance.derivation_chain | ForEach-Object {
    Write-Host "  [$($_.stage.ToUpper())] $($_.description) (at $($_.timestamp))"
}
```

### Step 7: Span Drift Detection Job (AC-PRV-03 / Invariant I4)

Run the automated integrity job:

```powershell
$driftReport = Invoke-RestMethod -Method Post -Uri "$API_URL/v1/investigations/$INV_ID/evidence/drift-check" -Headers $HEADERS

Write-Host "Drift Check Report:"

Write-Host "  Drifted Spans: $($driftReport.drifted_count)"

```

### Step 8: Evidence Review, Dispute & Withdrawal (EVID-004..005)

```powershell
# 1. Review and dispute evidence
$dispute = Invoke-RestMethod -Method Patch -Uri "$API_URL/v1/investigations/$INV_ID/evidence/$EVIDENCE_ID/review" -Headers $HEADERS -ContentType "application/json" -Body (@{
    review_state = "disputed"
    dispute_rationale = "Subject to ongoing privilege challenge in Delaware Chancery Court"
} | ConvertTo-Json)
Write-Host "Review State: $($dispute.review_state)"

# 2. Withdraw evidence
$withdrawn = Invoke-RestMethod -Method Post -Uri "$API_URL/v1/investigations/$INV_ID/evidence/$EVIDENCE_ID/withdraw" -Headers $HEADERS -ContentType "application/json" -Body (@{
    exclusion_reason = "Withdrawn pursuant to attorney-client privilege ruling"
} | ConvertTo-Json)
Write-Host "Evidence Status: $($withdrawn.status)"
Write-Host "Exclusion Reason: $($withdrawn.exclusion_reason)"
```
