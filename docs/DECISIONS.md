# CASEFILE DECISION LOG

Decisions D1–D28 are the product and architecture decisions recorded in `PRD.md` §66 and
are reproduced here unchanged. D29 onward are engineering decisions made during the build.

**Rules.** A decision recorded here is binding until explicitly superseded by a later
numbered decision. When the PRD is ambiguous, follow HANDOFF §7.2: check §66 and §64
first, then the ten invariants, then §4.6 product principles, then choose the option that
is more traceable, more human-controlled, or more conservative about epistemic claims —
in that order — and record it here. Do not ask the user about every ambiguity; ask about
the ones that change the architecture or violate a principle, and decide the rest.

**Standing Rule D62 (GCS Object Immutability & Preservation):** Never delete, overwrite, or move an object in any GCS bucket. No `gcloud storage rm`, no `bucket.deleteFiles()`, no `file.delete()`, no `--recursive` anything next to a `gs://` path, no lifecycle rule that expires objects. Ingestion reads. If a test needs a clean slate, it creates its own prefix and leaves it. If cleanup seems necessary, stop and report instead.

A decision that would violate one of the ten invariants (HANDOFF §1.3) is not a decision.
It requires explicit user sign-off in the conversation, and it is recorded as a deviation.
